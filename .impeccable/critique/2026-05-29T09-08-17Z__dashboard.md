## Anti-Patterns Verdict

**LLM assessment**: Not immediately AI-generated. OKLCH token system, tabular-nums discipline, and aria coverage show real craft. Structural failure: welcome banner → profile card → data table is the most generic possible dashboard layout. No allocation visualization, no P&L.

**Detector**: Clean scan. Zero automated findings.

## Priority Issues

**[P1] No data visualization** — portfolio allocation invisible without scanning table. Fix: asset allocation donut from invested_amount grouped by asset class. Implemented.

**[P1] Missing P&L** — invested_amount and current_value/nav both in API. Unrealized gain never computed. Fix: compute totalCurrentValue, gain, gainPct. Implemented.

**[P1] No column sorting** — 20-30 row table with no sortable columns. Fix: sortable th with click handler, local sort state, visual indicator.

**[P2] Profile card wastes viewport** — email + role zero-task-value on daily use. Fix: collapse to identity line in header or move to settings.

**[P2] No data freshness** — last_updated on each holding, never shown. Fix: show most-recent last_updated in card header.
