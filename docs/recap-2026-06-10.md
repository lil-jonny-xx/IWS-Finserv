## Overview

The previous recap closed with the portal automated end-to-end for mutual funds and the equity pipeline freshly scaffolded. This week was about making equity real: getting all three brokers actually authenticating and syncing across every entity, building the reporting layer the business runs on (Excel reports + manual-asset entry), hardening the CAS automation so it stops silently missing runs, and turning the dashboard into a true multi-asset portfolio overview. ## Phase 8 — All Brokers Live, Sector Grouping, Security Round 4 (2026-06-04)

### Broker auth fixes
- **Angel One** — SmartAPI's `setAccessToken()` double-prefixed `Bearer `, producing `Bearer Bearer <token>` → every fetch returned "Invalid Token". Fixed by `removeprefix("Bearer ")`.
- **Dhan** — SDK breaking change: `dhanhq(client_id, token)` → `dhanhq(DhanContext(client_id, token))`.

### Equity table — sector grouping with broker badges
New `classify_sector(symbol, isin)` keys off the ISIN prefix (Sovereign Gold Bond / Gold ETF / Silver ETF / ETF / Equity). Added a `sector` column to `equity_holding` (migrated + backfilled). Frontend regrouped by sector with coloured broker badges (orange Angel One, blue Zerodha, green Dhan) instead of broker sections.

### Overview page fix
Showed "no data" despite holdings existing — backend hadn't been restarted, plus a SQL bug (`h.asset_class`/`h.security_type` live on `security_master`, not `holding`). Fixed the JOIN.

### Security audit — round 4 (7 findings, all remediated)
| # | Finding | Fix |
|---|---|---|
| M1 | Stale JWT role claim — demoted admin kept access for 2h | `_live_role()` re-queries `users.role` from DB on every gated request |
| M2 | Non-atomic broker token write (chmod race) | Write `.tmp` → chmod 600 → atomic `rename()` |
| M3 | Playwright `--no-sandbox` | Accepted risk — worker already runs unprivileged; documented |
| M4 | PAN + CAS emails in `.env` | Moved to DB (`pan_group.pan_number`, `entity.cas_email`); loaded via JOIN; removed from `.env` |
| M5 | Nginx server-header exposure | `proxy_hide_header Server` / `X-Powered-By` |
| M6 | PII (names/emails/PAN) in worker logs | Removed from CAS parser/automation/trigger log lines |
| M7 | Screenshots world-readable (664) | `chmod 600` on save + retroactively on 21 existing files |

Also fixed a log-ownership trap: `mis-portal-cas-auto.log` was owned by `cams-worker` while the worker runs as `SAdmin` — same silent-crash failure mode as the Jun 1 complete miss. Chowned back to `SAdmin`. Comprehensive README added.

## Phase 12 — Cron Alerting, XIRR, Equity Print Report, Repo Cleanup (2026-06-09)

### Cron failure alerting — the missing safety net
- `workers/alert.py` — sends a failure email via Gmail API (`gmail.send` scope), auto-refreshing the token; never raises
- `workers/cron_wrapper.py` — transparent subprocess wrapper; on non-zero exit emails the last 60 lines of output. **All 6 daily workers now run through it.**
- `oauth_setup.py` updated for the `gmail.send` scope and `run_local_server` flow (Google killed OOB)

This closes the long-standing "silent failures go unnoticed" open item from the last recap.

### Equity price worker → systemd timer
Moved off per-minute cron to a `oneshot` service + `OnUnitActiveSec=60` timer; fixed the log path from `/home/SAdmin/` → `/var/log/`.

### CAMS "From Date" fix
Angular Material marks date inputs `readonly`, so Playwright's `type()` silently failed and CAMS defaulted to current-FY start (0 transactions for old folios). New `_type_into_date_input()` strips `readonly`, types via keyboard, uses exact IDs, and detects form-reset (invalid-password) as a hard failure instead of an ambiguous submit.

### Pooled XIRR — combined MF view
`effectiveCombined` was only overlaying `xirr_inception_pct` onto per-folio CAS rows. Now returns the full true-pooled response from `/api/v1/holdings/combined` (computed from `mf_transaction`), falling back to local rows only when empty.

### Equity daily print report
New `build_equity_daily_print()` — single sheet with a grand-total section (DHR+HHR+SDR merged by ISIN) plus per-entity sections, 13 columns including within-entity and cross-entity exposure %. Wired into `generate_reports()`.

### Combined report — sub-section structure
Fixed Income, Equity, and Alternates now break into labelled sub-sections (MF Debt vs PPF; MF Equity/Hybrid vs Direct Equities vs PMS vs AIF; Gold/Overseas/Forex) each with its own subtotal — previously everything pooled under one unlabelled "Total Equity".

### Repository cleanup
Removed accidentally-tracked generated files (`reports/*.xlsx`, `logs/*.log`), untracked the work-log markdowns and `CLAUDE.md`, fixed a broken `.xlsx ` (trailing-space) gitignore pattern, and stripped `Co-Authored-By` lines from history via `filter-branch` + force push.
