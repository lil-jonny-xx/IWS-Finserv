## 2. CSP Nonce Fix — Force Dynamic Rendering (commit `1b4b243`)

**Root cause:** `layout.tsx` was statically pre-rendered. `proxy.ts` injects `nonce-x` into `script-src` on every request. Static pages had no nonce in their HTML → browser blocked all JS → login and dashboard showed infinite loading spinner.

**Fix:** `export const dynamic = 'force-dynamic'` added to `app/layout.tsx`. All pages now SSR per-request; Next.js stamps the nonce correctly.

**Also fixed:** Tailwind class `break-words` → `wrap-break-word` on dashboard `h1`.

Files: `app/layout.tsx`, `app/dashboard/page.tsx`

## 5. Path Traversal Fix — Gmail Worker (commit `f083e51`)

**Vulnerability:** `_download_attachment()` in `gmail_worker.py` used `os.path.join(save_dir, filename)` where `filename` is a sender-controlled value from the email attachment. An attacker-crafted `filename` (e.g. `../../etc/passwd`) or absolute path would write outside `save_dir`.

**Fix in `mis-portal/workers/gmail_worker.py`:**

1. `os.path.basename(filename)` strips any directory components.
2. `re.sub(r"[^\w\-.]", "_", ...)` sanitizes remaining non-safe characters.
3. If sanitized name doesn't end in `.pdf`, falls back to `cas_{msg_id}.pdf`.
4. Defense-in-depth: `os.path.realpath(save_path).startswith(os.path.realpath(save_dir) + os.sep)` confirms confinement after join; rejects and logs if check fails.
