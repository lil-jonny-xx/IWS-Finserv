## 1. Equity Holdings — New Module (`mis-portal/equity/`)

New package covering three brokers: Zerodha, Angel One, Dhan.

### DB Migration — `equity/db_migrate_equity.py`

Run-once script. Creates:

| Table | Purpose |
|---|---|
| `equity_holding` | Live snapshot of each stock per entity/broker |
| `equity_holding_history` | Daily EOD snapshots for weekly/YTD P&L anchors |

Also extends existing tables:
- `security_master` — adds `exchange` column (NSE/BSE)
- `holding` (MF) — adds metric columns (weekly change, YTD P&L, exposure %, CAGR) to match equity layout

### Broker Adapters — `equity/brokers/`

| File | Broker | Method |
|---|---|---|
| `zerodha.py` | Zerodha / Kite | Kite Connect REST API — holdings endpoint |
| `angel_one.py` | Angel One | SmartAPI — portfolio holdings |
| `dhan.py` | Dhan | Dhan API — holdings list |

Each adapter normalises its response into `EquityHolding` objects (`equity/models.py`).

### Equity Sync Worker — `equity/equity_sync_worker.py` (392 lines)

Runs at **7:00 AM IST** (after `token_refresh_worker`).

Per entity + broker pair:
1. Fetches live holdings from broker API
2. Normalises to `EquityHolding`
3. Computes all metrics:
   - `prev_week_value` — from `equity_holding_history` for last Friday
   - `pnl_ytd` — from `equity_holding_history` for 1 Jan (or earliest available)
   - `first_invested_date` — preserved on existing rows; set to today on first insert
   - `exposure_pct` — `current_market_value / sum(all entity holdings) × 100`
4. Upserts into `equity_holding`
5. Writes daily snapshot to `equity_holding_history`

```
Cron: 30 1 * * * .venv/bin/python mis-portal/equity/equity_sync_worker.py
```

### Token Refresh Worker — `equity/token_refresh_worker.py` (58 lines)

Refreshes broker API access tokens before the sync worker runs. Runs at **6:30 AM IST**.

## 2. Live Price Worker — `workers/equity_price_worker.py` (433 lines)

Fetches live LTP (last-traded price) every minute during market hours and recomputes all derived metrics in-place.

- **Market hours guard:** exits immediately outside Mon–Fri 09:15–15:30 IST
- **EOD snapshot:** writes to `equity_holding_history` in the last 5 minutes before market close (15:25–15:30)
- **Brokers:** Zerodha, Angel One, Dhan — reads credentials from `broker_api_credentials` JSONB column

```
Cron (fallback): * * * * * .venv/bin/python mis-portal/workers/equity_price_worker.py
```

## 3. MF Metrics Worker — `workers/mf_metrics_worker.py` (385 lines)

Runs at **10:15 PM IST** (after `amfi_nav_worker`). Reads the latest NAV already stored on each holding row, fetches historical NAV anchors from `nav_history`, and writes computed metrics back to `holding`.

| Metric | Source |
|---|---|
| `market_value_as_on` | `quantity × last_updated_nav` |
| `prev_week_value` | `quantity × closest NAV ≤ last Friday` |
| `weekly_change` | `market_value_as_on − prev_week_value` |
| `exposure_pct` | `market_value_as_on / entity_total_mf_value × 100` |
| `pnl_inception` | `market_value_as_on − cost_basis` |
| `pnl_ytd` | uses closest NAV ≤ Apr 1 (fiscal year start) |
| `returns_inception_pct` | `pnl_inception / cost_basis × 100` |
| `cagr_inception_pct` | `(current/cost)^(1/years) − 1` |

```
Cron: 45 16 * * * .venv/bin/python mis-portal/workers/mf_metrics_worker.py
```
