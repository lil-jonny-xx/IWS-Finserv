## New DB Tables

### `manual_input`
- Stores manually entered portfolio values (PMS, bank balances, overseas assets, gold ETF, etc.)
- Schema: `id`, `entity_id` (FK), `category` VARCHAR(60), `label` VARCHAR(200), `cost`, `current_value`, `prev_week_value`, `currency` (default INR), `raw_amount`, `fx_rate`, `inception_date`, `notes`, `updated_by` (FK users), `updated_at`
- Each save inserts a new row — history preserved; latest fetched via `DISTINCT ON (entity_id, category, label)`

### `generated_report`
- Tracks every report generation run
- Schema: `id`, `report_type` (individual/combined), `entity_id` (nullable FK), `entity_name`, `filename`, `filepath`, `as_of_date`, `generated_by` (FK users), `generated_at`

Migration script: `workers/db_migrate_manual_reports.py`

## Report Generator (`workers/report_generator.py`)

- `build_individual_report(conn, entity_id, entity_name, as_of)` → openpyxl Workbook
- `build_combined_report(conn, as_of)` → openpyxl Workbook
- `generate_reports(conn, generated_by_user_id)` → 7 files per run, saved to `/var/www/mis-portal/reports/YYYY-MM-DD/`, records in `generated_report` table

### Excel layout
- Individual: 13 columns — Asset/Fund, Inception Date, Cost, Mkt Val 31-Mar, Current MV, Prev Week, Weekly Change, P&L YTD, P&L Inception, Returns YTD%, Returns Inception%, CAGR%, Remarks
- Combined: 11 columns — Asset/Fund, Entity, Source, Cost, Mkt Val 31-Mar, Current MV, Prev Week, Weekly Change, YTD Returns%, Inception Returns%, CAGR%
- Styled: navy headers (`1F3864`), section headers (`D6E4F0`), total rows (`BDD7EE`), alternating row tints

### Data sources per section
- MF holdings + NAV from CAS DB (`holding` table + AMFI NAV)
- Equity from broker sync (`equity_holding` table)
- Manual values (PMS, bank, overseas, gold, FX, etc.) from `manual_input` table
- FX rates from `fx_rate` table for cross-currency conversion

## Backend API Additions (`main.py`)

| Endpoint | Method | Description |
|----------|--------|-------------|
| `/api/v1/manual-inputs` | GET | Admin only — latest row per (entity, category, label) |
| `/api/v1/manual-inputs` | POST | Admin only — re-auth via password verify, validates category/currency, inserts rows, writes audit_log |
| `/api/v1/fx-rates` | GET | Authenticated — latest FX rate per currency from `fx_rate` table |
| `/api/v1/reports` | GET | Admin only — last 100 generated_report records |
| `/api/v1/reports/generate` | POST | Admin only — calls report_generator, writes audit_log (rate limited 5/min) |
| `/api/v1/reports/{id}/download` | GET | Admin only — FileResponse streaming xlsx |

- Valid categories (16): Fixed Deposits, Bonds, Debentures, Unlisted Bonds, NCD, Direct Equity, PMS, AIF, REITs, InvITs, Real Estate, Gold ETF, Gold Physical, Overseas Equity, Overseas Funds, Bank Balance, Forex Holdings, Other
- Valid currencies (7): INR, USD, EUR, GBP, SGD, AED, JPY
- Re-authentication: password compared via bcrypt against `users` table before any save
