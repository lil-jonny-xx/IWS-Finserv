### `workers/alert.py` (new)
- Sends failure email via Gmail API (`gmail.send` scope)
- Reads central OAuth token from `workers/gmail_token_central.json`
- Auto-refreshes expired token and saves back to file

- Transparent subprocess wrapper for all cron workers
- Usage: `cron_wrapper.py workers/some_worker.py [args]`
- Passes stdout/stderr through so cron log captures everything
- On non-zero exit: sends failure email with last 60 lines of combined output
- All 6 daily workers now invoked via `cron_wrapper.py` in crontab

## CAMS From Date Fix (Item 8)

### Root Cause
- Angular Material sets `readonly` attribute on date inputs to block browser autocomplete
- Playwright's `loc.type()` throws "not editable" silently on readonly inputs
- Caught by `except Exception: continue` — silently fell through to next selector
- CAMS defaulted to current FY start (01-Apr-2026) → 0 transactions for long-held funds

### Fix (`workers/cams_trigger_worker.py`)
- `_type_into_date_input(loc, value, page)`: removes `readonly` via `page.evaluate()`, then uses `page.keyboard.type()` + Tab to trigger Angular DateAdapter parsing
- Added exact IDs `#fromDate_new` and `#to-date-input` as primary selectors
- Added label variant probing (uppercase/titlecase) before falling back to CSS selectors
- Added form-reset detection: CAMS clears form fields on invalid PDF password — now detected as hard failure instead of ambiguous submit

## Equity Daily Print Report

### `build_equity_daily_print(conn, entity_codes, as_of)` — new function in `report_generator.py`

**Structure** (single sheet "Equity Daily Print"):
1. Grand Total section — all DHR + HHR + SDR stocks merged by ISIN, sorted by CMV desc
2. DHR section — DHR stocks only, sorted by CMV desc
3. HHR section
4. SDR section

**Columns** (13):
Script Name, Ticker Name, Last Purchase Date (blank — no transaction history), Quantity, Avg Purchase Price, Total Purchase Cost, Current Market Price, Total Current Market Value, Total P&L (Inception), Inception Returns %, Stock Exposure (CMP) %, Stock Exposure (Cost) %, Change in Exposure

**Exposure % logic**:
- Data rows: stock CMV / entity total CMV (within-entity share)
- Entity total rows: entity CMV / grand total CMV (cross-entity share)
- Grand total section: stock CMV / all-entities total CMV

**Multi-broker merge**: same ISIN across multiple brokers collapsed into one row (qty/cost/CMV/P&L summed; avg cost recalculated)

### `generate_reports()` updated
- Now also generates `Equity_Daily_Print_YYYYMMDD.xlsx` (report_type=`equity_daily`, entity_name=`DHR / HHR / SDR`)
