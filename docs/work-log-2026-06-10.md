## MF + Equity — Inception-Date and Weekly-Change Derivation Fix

### Root cause
- `inception_date` for MF holdings was being derived from the first `nav_date` available in the DB rather than the actual purchase date — producing wrong "since inception" labels and inflated CAGR figures
- Weekly change was computed against a stale cached value instead of the `prev_week_value` column, causing incorrect week-on-week delta for holdings with mid-week updates

### Fix (`report_generator.py`, `mf_metrics_worker.py`)
- `inception_date` now sourced from `MIN(transaction_date)` on `mf_transaction` for each (entity, folio, scheme) group — falls back to `first_nav_date` only if no transaction history exists
- Weekly change recomputed from `current_market_value - prev_week_value` using the stored column, which is updated every Monday morning
