# Worklog — 2026-06-12

## Auth — Idle-Timeout Auto-Logout

### `app/IdleTimeout.tsx` (new)
- Client-side component mounted in root layout — covers every authenticated page, skips `/login`
- Passive activity listeners (`mousemove`, `keydown`, `click`, `scroll`) stamp `lastActivity` in `localStorage`
- 15 s interval checks elapsed idle time; past threshold → `POST /auth/logout` (revokes token in Redis + clears cookie) → redirect to `/login`
- Default threshold: 30 min, env-tunable via `NEXT_PUBLIC_IDLE_MINUTES`
- Leverages existing logout endpoint — no new backend work

### `app/layout.tsx`
- `<IdleTimeout />` mounted alongside `<BenchmarkTicker />`; both present in all authenticated views

## Jarvis — Cap Web Searches per Answer

### `assistant/engine.py`
- `WEB_SEARCH_MAX_USES` reduced from 5 → 4 (env-tunable)
- Web search results are re-read across every subsequent agentic loop iteration; each extra search compounds context size and token cost more than linearly
- At 4 uses, fundamentals research (valuation + profitability + growth + leverage + sector = 5 queries planned) gracefully truncates at 4 with the model summarising from available data
- Estimated blended cost impact: ~$0.05/msg saving at heavy usage
