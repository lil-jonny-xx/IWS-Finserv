# Worklog — 2026-06-15

## Dhan token freeze — retry on TOTP generation

Dhan tokens are minted via PIN+TOTP `generateAccessToken` (a non-renewable token type), so `_renew_token` always fails (DH-901/DH-905) and every run falls back to TOTP generation. That path had no retry — a single transient "Invalid TOTP" rejection left the entity's access token invalid for the whole day, freezing its `equity_holding` rows at stale prices until the next 06:30 refresh (stranded 41 holdings / ~₹1.26 Cr).

- `_generate_token` now retries up to 3×, taking a fresh code just after the next 30s TOTP window on each retry so a code can't expire in transit. Added a request timeout; happy path still succeeds on attempt 1.

## MF metrics — suppress CAGR/XIRR when the ledger doesn't reconcile

A holding whose `mf_transaction` signed unit-sum diverges from its quantity (e.g. an incomplete CAS listing) produced garbage time-weighted returns — DHR's ICICI Liquid fund showed 49% XIRR against a 0.5% CAGR.

- Added `ledger_reconciles()` (tolerance `max(1 unit, 0.5%)`); time-weighted metrics are gated on it. When the ledger doesn't tie out, CAGR/XIRR are left NULL while absolute P&L/return are still computed from `cost_basis` (the registrar figure). Logs a warning naming the affected holding.

## Overview — fold manual entries into asset-class buckets

- Aggregate manual entries (PPF, PMS/AIF, unlisted, startups, overseas, cash) into `/api/v1/overview` alongside MF and equity via a new `_fetch_manual_overview_rows` helper + `MANUAL_ASSET_CLASS` map. Values are already INR (no FX); manual rows have no ledger so cagr/xirr stay None and pnl = current_value − cost.
- Stopped collapsing per-entity bars into a single "MF" bucket — each real asset class (EQUITY/FIXED_INCOME/ALTERNATES/DIRECT_EQUITY/HYBRID/ARBITRAGE/CASH) is kept distinct, matching the top-level donut and reports. Added dashboard colours/labels for HYBRID, ARBITRAGE, CASH.
