# Worklog — 2026-06-16

## Dhan LTP — restored via holdings feed

`DhanAdapter` called dhanhq's removed v1 `get_market_feed_ltp` (AttributeError on every call in installed 2.2.0) and authed with the expired DB token, so intraday Dhan prices froze silently while holdings sync kept working off the valid `.env` token.

- Read LTP from `get_holdings()` `lastTradedPrice` for both entities (HHR, Rajani Corp) — no ticker_data/securityId/scrip-master needed.
- Lazy token refresh: only re-auth (TOTP from `.env`) and retry on auth failure.
- Hardened run loop: log ERROR and skip `mark_broker_synced` when zero prices come back, with per-broker missing-price counts.
- Verified live during market hours: 41/41 Dhan holdings refreshed.

## PMS (Nuvama WealthSpectrum) — full vertical slice

- **Migration:** `pms_holding` (entity_id, holding_type, security_name, isin, quantity, avg_cost, cost, current_price, market_value, weight_pct) with `UNIQUE(entity_id, holding_type, security_name)` for delete-then-insert upserts.
- **Worker:** Playwright `nuvama_pms_worker` logs into the Nuvama PMS portal, parses the Portfolio page (equity + cash, with weights and totals), upserts per entity. Logs in once and reuses the authenticated session (single-live-session license); fast-fails on "Invalid login as per license" and logs out to free the seat.
- **API:** `GET /api/v1/pms/holdings` returns holdings grouped into equity/cash with equity_total, cash_total, combined total, cost and P&L (mirrors equity auth + entity-scoping).
- **Frontend:** new `/pms` page (equity/cash/total cards + grouped holdings table); PMS nav link across all section pages.
- **Overview:** `_fetch_pms_overview_rows` folds PMS equity into EQUITY and PMS cash into CASH, so dashboard totals, donut and per-entity breakdown include the Nuvama portfolio.

## NAV → metrics chaining

- `market_value_as_on` was only recomputed by separately-timed cron runs, so any other NAV refresh left market values stale. `amfi_nav_worker` now runs `mf_metrics_worker` at the end of a successful run (isolated so a metrics failure never undoes the NAV save), keeping `market_value_as_on = units × latest NAV`.
