Three compounding bugs hid most holdings from the admin All-entities view:

- **Holdings API routing:** `/api/v1/holdings` routed an admin with no `entity_id` param into the member branch, resolving to the admin account's own `users.entity_id` (IWS, 6 holdings). Also fixed combined-mode sort, hid the entity filter pill in combined view, corrected `colCount` (+8 not +11), and removed the `max-h-[75vh]` cap that left a blank gap below short row sets (switched to `overflow-x-auto`).
