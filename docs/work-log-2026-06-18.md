# Worklog — 2026-06-18

## Broker cash, PMS-account routing & Nuvama intraday pricing

Three related broker-account features sharing the sync/price workers:

- **Broker cash:** a `broker_cash` table plus `fetch_cash_balance()` on the Zerodha (Kite margins), Angel One (RMS limits) and Dhan (fund-limit) adapters. The sync worker upserts available cash per (entity, broker); a failed token is isolated so it keeps the last known balance instead of writing a misleading 0. Surfaced on the Equity page (Cash Balance / Value + Cash) and refreshed intraday by the price worker.
- **PMS routing:** Rajani Corp's Zerodha account is a discretionary PMS, so its holdings now land in `pms_holding` (PMS page) via a new `PMS_BROKER_MAP` and `sync_pms_broker()`, with cash as a 'cash' row and weights over equity+cash. `update_pms_prices()` refreshes intraday from the same broker feed.
- **Nuvama PMS pricing:** scraped positions (no broker account) are priced by ISIN via `isin_lookup` (Dhan scrip-master ISIN → NSE/BSE symbol → Zerodha LTP). Dormant until the scrape populates `pms_holding.isin`. Also fixed `nuvama_pms_worker._prev_snapshot_total` reading a RealDictCursor row by index instead of column name.

## Overview — PMS and Real Estate as distinct asset classes

- PMS holdings now report in their own **PMS** bucket instead of folding into EQUITY, so the dashboard shows them as a separate slice.
- Added a `properties` manual category mapped to a new **REAL_ESTATE** class, with colours and labels on the donut. PMS cash still folds into CASH.

## Reports — broker rollup + new sections

- All Assets report collapses direct equity to one row per broker with blended returns and a value-weighted CAGR, and adds PMS, broker-cash and real-estate sections.
