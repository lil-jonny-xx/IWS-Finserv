# Worklog — 2026-06-20

## International / foreign equity — foundation

Brought IBKR, Vested and DBS international holdings into the system end-to-end, with multi-currency support and money-weighted returns.

### Data model & FX
- **Multi-currency holding model** + FX conversion for international brokers — holdings carry a native currency and native amounts, converted to INR for the dashboard.
- **XIRR helper** — money-weighted return computation shared across workers.

### Broker adapters & scrapers
- **International broker adapters** (IBKR Flex, Vested, DBS) via a shared feed cache.
- **Vested and DBS portal scrapers** (Playwright).
- Daily sync integrates the international brokers (FX, ledger XIRR, snapshot date).
- **IBKR inception backfill** + a trade-ledger table for XIRR.

### API & UI
- Holdings API exposes currency, native amounts and XIRR.
- Equity UI shows native currency, XIRR and snapshot date for international holdings.

### Housekeeping
- `.gitignore` excludes Vested/DBS scraper artifacts and the feed cache.
