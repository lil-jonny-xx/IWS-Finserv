## Broker-cash refresh — throttled

The price worker (fired every minute during market hours) called `refresh_broker_cash()` on every loop. DHR's Angel One token gets invalidated intraday (single active session), so its RMS call failed ~392×/day with 'Invalid Token' spam even though the balance is correct.

- Gate the refresh on `broker_cash.MAX(updated_at)`: only refresh when the newest row is >30 min old. Cuts ~392 → ~12 attempts/day and refreshes once at market open. The daily sync still refreshes unconditionally.

## Dhan webhook — hardening (white-hat)

The `/api/v1/dhan/postback` webhook is unauthenticated by necessity (Dhan sends no JWT/signature). Hardened ahead of any state-changing processing:

- Optional `DHAN_POSTBACK_SECRET`: when set, require it via `X-Postback-Token` header (or `?token=`), constant-time compared with `hmac.compare_digest`. Unset = backward-compatible (open), logs a warning.
- Redacted logging: log only non-sensitive routing fields (orderId, status, txn type, symbol).
- Rate limit 120/min via the existing limiter.
