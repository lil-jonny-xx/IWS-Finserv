# Worklog — 2026-06-25

## Broker token self-heal, foreign price feed, throttle-safe IBKR

- **Angel One:** `_smart_client` reads the daily-refreshed token from `tokens.json` before the stale `.env` pin (the mismatch froze cash/holdings on AB1007 all day); refresh now also updates `os.environ`, and `fetch_*` reauth+retry once on intraday single-session death.
- **Foreign equity price feed:** new `workers/foreign_price_worker.py` prices US holdings from an independent feed (Finnhub → Twelve Data → yfinance) decoupled from the broker scrape, with a US-market-hours guard + EOD snapshot; systemd unit in `deploy/systemd/`.
- **Metrics:** `portfolio_returns` no longer double-converts foreign broker cash (was ~95× inflated); annualised CAGR/XIRR are only emitted once a holding is held **≥1 year** (sub-year shows the absolute return) across price/txn/sync workers.
- **IBKR:** holdings and cash share one Flex query → fetch the statement once and parse both (`fetch_positions_and_cash`); in-process + on-disk statement cache so a throttled (1001/1025) fetch falls back to the last good statement; new paced `ibkr_holdings_cash_worker.py` (one hit per login, refuses to write a partial aggregate).

## Equity — duplicate holdings, self-advancing YTD, snapshot XIRR

- **ISIN natural key:** the unique key was (entity, broker, symbol), so a broker ticker/series-suffix change for the same ISIN (VAML↔VAML-BE, SGBAUG28V↔-GB, …) inserted a second row and double-counted value. Swapped `equity_holding`'s natural key to (entity, broker, isin) — the upsert now conflicts on ISIN and adopts the broker's current ticker (self-healing). Foreign holdings keep the symbol key. `db_dedup_equity_holding_isin.py` does the one-time merge + constraint swap.
- **YTD self-advances:** `FY_START` was hardcoded to 2026-04-01; now computed from today so YTD doesn't become a multi-year measure after the 1-April rollover.
- **Snapshot-XIRR fallback:** `snapshot_xirr_worker.py` reconstructs a per-ISIN cashflow series from `equity_holding_history` and computes XIRR (same ≥1yr ann_guard), writing `xirr_inception_pct` only where the tradebook path left it NULL. Scheduled daily after the txn-metrics cron.
- **Stop nulling metrics-owned YTD:** wrapped `pnl_ytd`/`returns_ytd_pct` in `COALESCE(EXCLUDED.x, {tbl}.x)` so a NULL from the sync preserves the `equity_txn_metrics_worker` value instead of erasing it.
