The bulk of today was the **Alternates revamp** (Phases 1–3) plus a run of UI fixes. All work is committed on `main`; **deploy pending** (see Open items).

## IBKR — one Flex call per token/day

The daily `QUERY_ID` now bundles Open Positions + Cash Report + Trades (365d), so a single `SendRequest` per login yields everything — no back-to-back same-query regeneration that escalates the 1001 throttle into a 1025 lockout.

- `ibkr.fetch_all()` parses positions, cash and trades from one statement per login.
- `ibkr_holdings_cash_worker` upserts trades into `equity_trade_ledger` first (reusing `_parse_trade`/`upsert_ledger`, deduped by tradeID) so `ledger_metrics()` recomputes XIRR/first-invested off the fresh ledger, then holdings + cash.
- Exactly one shot/day (`IBKR_FLEX_SEND_RETRIES=1`); throttled days fall back to the last good on-disk statement.

## Alternates revamp — Phase 1: Commodities (Gold/Silver)

Gold ETFs, sovereign gold bonds, silver ETFs and tracked commodities (IBKR uranium) moved off Equity / Foreign Equity onto their own page. Classification is curated + admin-overridable and runs in the daily sync.

- `equity/asset_class.py`: `classify_asset_class()` (curated symbol map, IN0* ISIN → gold for SGBs, keyword fallback) + override loader.
- `db_migrate_asset_class.py`: `asset_class` column on `equity_holding` + `foreign_equity_holding`, `asset_class_override` table, backfill.
- `main.py`: exclude gold/silver/commodity from `/equity` + `/foreign-equity` holdings; add `/api/v1/gold-silver/holdings`; overview buckets GOLD_SILVER / COMMODITIES (net worth unchanged); drop empty buckets from pie/bar.
- New `app/gold-silver/page.tsx` (later renamed **Commodities**) + nav link across pages.

## Phase 3: Unlisted / Startup funding rounds

Unlisted Equity and Startup holdings are valued from funding rounds and corporate events instead of a single hand-typed figure.

- DB: `unlisted_round` + `unlisted_event` tables; v2 migration adds `round_valuation`, `bonus_shares`, makes `factor` nullable.
- Valuation: current value = total shares (after splits/bonuses) × latest round's effective price-per-share; cost = Σ round investments. `_compute_unlisted` walks rounds+events **chronologically** over a running share pool — a SPLIT (ratio, `2` = 2-for-1) multiplies the pool, a BONUS (absolute share count) adds to it; per-share price adjusts so total value is preserved.
- `POST`/`GET /api/v1/unlisted-rounds` (admin writes, entity-scoped reads); manual-assets enrichment; delete cleanup. Derived cost/value written to a fresh `manual_input` version so Overview (ALTERNATES) keeps working.
- Manual Data gains a Rounds + splits/bonuses editor with a live aggregate preview (each event shows the new total share count). New read-only `/unlisted` page: aggregate summary + expandable per-company breakdown.
