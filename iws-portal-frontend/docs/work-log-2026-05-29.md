## 3. CSP Nonce Fix

**Commit:** `4ec1d23` · 07:08 UTC

**Root cause:** `layout.tsx` was statically pre-rendered. `proxy.ts` injects `nonce-x` into `script-src` on every request. Static pages had no nonce in their HTML, so the browser blocked all JS — login and dashboard showed infinite loading spinner.

**Fix:** Added `export const dynamic = 'force-dynamic'` to `app/layout.tsx`. All pages now render per-request (SSR), so Next.js stamps the nonce at runtime.

**Also fixed:** Tailwind class `break-words` → `wrap-break-word` on dashboard `h1`.

Files changed: `app/layout.tsx`, `app/dashboard/page.tsx`
